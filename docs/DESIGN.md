# 技術設計書 — The Life of a Star (revision 3)

太陽の一生 — 原始星の収縮から冷え切った黒色矮星まで — を、
**すべての色が公表データから導出され、一つも「選ばれていない」**
インタラクティブなブラウザ体験として描く。本書は最終形 (v0.5,
スイート 316 検査 ALL GREEN, ゲート 9/9) の設計と、その過程の回顧録である。

---

## 1. 三層構造

本作は「検証装置を最初に作る」逆順で構築された。

### Stage −1 — 検証ハーネス (`harness/`) : 最初に構築

作品より先に、作品を裁く装置を作った。

| 装置 | 役割 |
|---|---|
| `mirror.py` | 物理ミラー — パイプラインと独立に書かれた float64 数値検算 (既知解テスト) |
| `gate.mjs` | 視覚ゲート — 9 波形点を宣言済みカメラで headless 撮影。**プローブ(計器パネルの `[data-q]` 値)が不完全ならスクリーンショットは書かれもしない**(検査 48 の構造的強制) |
| `identity.py` | 恒等性ハッシュ — `data/derived` 全ファイルの SHA-256 合成。パスごとに記録 (v0.1〜v0.5) |
| `static_checks.py` | 静的検査 — 識別子純度 / 色リテラル禁止 / sin ハッシュ禁止 / **time-literals**(autoplay 実装と同時に起動した休眠検査) |
| `suite/` (13 ファイル) | 49 テスト系 316 検査 — 軌道忠実度・色連鎖・粒状斑・周縁減光・地球・冷却・星雲・空・プローブ・**画素測定**・取得完全性・fork 完全性 |
| `census.mjs` / `parallax.mjs` | **外部置換規則**による検査 — 出荷ソースは不変のまま、スクラッチコピーの宣言済み定数一つを置換 (等級限界 6.5→30 / 観測基線増幅)。置換先はドリフトガード付き |
| `userpaths.mjs` | **報告経路の再現** — ユーザーが実際に踏んだ操作 (ボタン/スライダー/再生) を無置換の実アプリで再現し画素測定 |
| `layers.mjs` | 層分解 — void / 帯 / 星クアッド / 点群を一層ずつ消して撮影し、背景異常を減算で帰属 |

**判定哲学**: スイートが判事である。テストは実装より先に書かれ、
修正は記録され、閾値の緩和は必ず理由と測定値を添えて宣言される
(無言の緩和はしない)。視覚予算は「収束」でなく「宣言済みレンジの
所属」で判定する — 受理済みビルドで測定し、レンジとして宣言し、
以後のビルドはレンジ内に留まることを示す。

### Stage 0 — オフラインパイプライン (`pipeline/`) : Python, float64

実行時に何も取得しない。すべての物理・色はここで表に焼かれる。

- **取得** — `manifest.json` のチェックサム付き台帳に対して取得。
  **フォールバックは存在しない**: 欠けたソースはパイプラインを名前付きで停止させる
  (`sources.require()` が単一の関門)。
- **軌道** — MIST v1.2 EEP トラック (1.0 M☉, [Fe/H]=0) が唯一の物理的権威。
  補間は常に **EEP 添字空間**で行う (年齢の線形補間はしない)。
- **色連鎖** — スペクトル → CIE 1931 2° 等色関数 → XYZ → 線形 sRGB →
  **Oklab 色域写像** (色相・明度一定、彩度圧縮)。**Planck 関数はどこにもない**
  (TiO が 83% 削る場所を Planck は 9% しか削らない — スペクトルで検査済み)。
  ホワイトバランスもない。
- **スペクトル格子** — BT-Settl / ATLAS9 / TMAP2 (567) + Koester DA (160) +
  全域 EUV SED (215)、SVO SSAP 経由。格子の所有権関数と継ぎ目は測定済み
  (fork 15: 支持境界での端評価)。
- **周縁減光** — Neilson & Lester 2013 球面則 + Claret & Bloemen 2011 平面則
  (VizieR)。球面則は限界で正当に負へ抜けるため、μ を [μ0, 1] に再写像
  (fork 18 修正 — 「黒く塗った縁」の修正)。
- **粒状斑** — 圧力スケール高から導出された粒径 D、枚数 N = 4R²/D²。
  テクスチャは手続き的だが**スケールは導出値** (画素自己相関検査 t41 で照合)。
- **地球** — 軌道平均 ODE (質量損失 + 潮汐抗力)、台帳=状態の帰属方式、
  rtol スケーリングで数値誤差と簿記を判別、solve_ivp 終端イベント。
- **冷却** — Bédard et al. 2020 (Montreal)。データ地平線 (~1470 K) より先の
  **領域 B** は宣言済み単一則 (Debye 指数則、値と微分で繋留)、画面上でも
  「extrapolated」と明示される。
- **星雲** — 相互作用する恒星風 (interacting winds) の薄殻解。輝線スペクトル
  は同じ CIE 連鎖を通る。
- **空** — Gaia DR3 裸眼カタログ (11,905 星、Hipparcos 明端 132)、
  Milky Way 帯 (HEALPix nside 32 積分光、同じ連鎖)、MW ポテンシャル
  (Miyamoto–Nagai 円盤 + Hernquist バルジ + NFW ハロー、v_c(R0)=220 km/s)。
  128 エポック (−4.8 Gyr 〜 +28.5 Gyr)。太陽の銀河周期 243.9 Myr、全行程 136.6 周。

### Stage 1 — ブラウザアプリ (`app/`) : 実行時取得ゼロ

ローカルの Stage-0 表だけを fetch する。表の不在は**名前付きの可視の拒否**
として表示される (「空白は情報である。代用品はデータの形をした嘘である」)。
Three.js は同梱・import map で固定。

| モジュール | 役割 |
|---|---|
| `main.js` | 編成。スライダー→弧長 s→EEP→表参照→各層更新。自動再生 (PLAY_SPAN_S=120 s)。宣言構図 (既定 d4/az0/alt25、終焉 8/90/25) |
| `star.js` | 全画面レイマーチの恒星。fork 30 トーン (場面参照 Reinhard + 白解決)、μ 再写像、SLICE_CAL 0.77 格子、後段レーン、符号化後三角ディザ |
| `skyfield.js` | 星野。**毎フレーム f64 で方向計算**(カメラ随伴シェル R_DRAW=1e4 — 生のパーセク座標は f32 頂点段で死ぬ、実測)。円筒位相アンラップ格納 (fork 32)、スタンドイン (fork 33) |
| `band.js` | 天の川帯。正距円筒テクスチャ、**uv はフラグメント毎に計算**(頂点補間は極で弧を塗る — 「不自然な半円」の修正) |
| `eye.js` | 観測者。fork 28 (暗順応 τ=4.5 s 圧縮宣言) + fork 35 (**可視光駆動** f_vis) |
| `nebula.js` | 薄殻星雲。弦長比例発光、C_EQ=3 赤道増強、**表の地平線に繋留された提示ランプ** |
| `void.js` | 虚空の絵画的深み。fork 34 — ディザ + **桿体視で退場**(「描いたものは計算されたものと競わない」) |
| `hr.js` `panel.js` `curves.js` | 計器群。パネルがプローブ面 (fork 12) — 検証はパネルを**読む**だけで、出荷ソースにテストフックはない |

## 2. 主要な設計決定 (fork 記録より抜粋)

正典は `pipeline/constants.py` 冒頭の FORK BLOCK (35 fork、検査 t49 が
理由・日付・支配定数の完全性を強制)。特筆すべきもの:

- **fork 14** — トラックが黒板値と食い違えば**トラックが勝つ**。太陽は 4.57 Gyr
  時点で +76 K / +10.6% L。飲み込み時刻 6.766 Gyr は黒板の 7.0–8.5 Gyr の外
  — 乖離は隠さず表示される (S&CS −0.82 Gyr 換算併記)。
- **fork 21** — 抗力トグルは地球の生死を**分けない** (抗力あり 6.766 / なし 6.892 Gyr)。
  トグルの意味は WHEN/WHERE: 抗力なしでも RGB 先端を 0.226 AU で躱した後、
  AGB が軌道を 0.589 AU 越えて到達する。
- **fork 29** — 純水素大気の燃え殻は「鈍い赤い炭」ではなく**青**へ抜ける。
  CIA (衝突誘起吸収) が赤外を閉じ、フラックスは可視の窓から逃げる
  (観測される IR-faint 系列)。
- **fork 30** — 輝度と色域の衝突は**白へ解決**。表示輝度要求 yD が色度の輝度
  天井 yCeil を超えるとき、白への混合重み w=(yD−yCeil)/(1−yCeil) は解析解
  であり調整値ではない。
- **fork 31** — 実基線では恒星視差は**サブピクセル**。「視差こそが実在感」という
  黒板の主張は、この視点では不正確 — 事実として記録。3D 真実は毎フレームの
  f64 方向計算が担い、増幅基線でハーネスが測定する。
- **fork 32** — 遠エポック間隔 300 Myr は全星の銀河周期 (200–280 Myr、差動)
  を超え、デカルト補間は**軌道を丸ごと弦で渡る** (前方円錐 0/11905、実測)。
  円筒座標・位相アンラップ格納で解決 (477/11905)。物理でなく表現の変更 —
  恒等性ハッシュ不変で立証。
- **fork 33** — 位相混合した円盤は統計的に**定常**: 星数は保存され、名前が
  入れ替わる。裸眼限界を離れた星は**スタンドイン**(同じ等級・色・距離・銀緯、
  方位角だけ黄金角列の宣言済み引き直し) に交代。むき出しの有限標本を描く
  ことは「空が空になる」という**偽**をデータの顔で示すことだった。
- **fork 34** — **絵具は空に譲る**。void は暗順応とともに退場 (0.012→0.0018)。
- **fork 35** — **眼は見える光で駆動される** (V(λ) 加重 f_vis)。赤色巨星は眼に
  4 倍暗く (TiO)、PN 星は 0.7 倍 (EUV)。そして fork 自身の前提が反証された:
  **CIA の燃え殻は赤外で暗くない** (f_vis(1772 K) = 太陽の 1.5 倍) —
  眼を掴む燃え殻は正しかった。スイートが恒久検査として主張する。

## 3. 検証の文化

1. **二人の判事** — スイート (客観) と批評家 (美的診断を測定に変換)。批評家の
   評決は必ず「測定可能な目標」に翻訳され、達成/未達が測定で記録される。
   最終盤に批評家役は退役し、自己レビュー体制へ移行した。
2. **攻撃ラウンド** — 「レンダを消してもテストが通るか?」に反例が構成できなく
   なるまでテスト自体を攻撃する。census (成分数)、t43 (画素色度 vs モデル変換)、
   t44 (帯構造スパン)、t42 実眼 (置換なし画素) はその産物。
3. **置換の対** — 定数置換で「経路の生存」を証明するテストは「出荷される体験」
   を測らない。すべての置換テストに無置換の画素テストを対にする
   (この教訓は実眼の星ゼロをユーザーに発見されて学んだ)。
4. **恒等性の系譜** — v0.1: eec5e4cf → v0.3: efa1bda3 → v0.4: 7e229316
   (fork 30/32/33/34 を通じ**不変** — すべて描画・表現側だった証明) →
   v0.5: 534f6f68 (f_vis 追加 — v0.4 以来初の宣言付き移動)。

## 4. 開発回顧録

### 第一部 — 五つのパス (v0.0–v0.4)

ハーネス→取得→軌道と色→恒星描画→地球と巨星→冷却と星雲→空、の順で
各パスは「緑のサブセット + 恒等性ハッシュ」のコミットとして閉じた。
最初の大きな驚きは fork 14: MIST トラックは黒板の数字より速い時計を持ち、
飲み込みは 6.766 Gyr に来る。ここで「トラックが勝つ」原則が確立し、以後
四つの前提 (fork 14, 19, 21, 29) がデータに反証されてもすべて記録の側が折れた。

### 第二部 — ユーザーとレビューアが見つけたもの

- **黄色い太陽** (報告) → バグではない。起動時は 4085 K の原始星 (琥珀色) で、
  現在の太陽は (1.000, 0.861, 0.851) の暖白 — 仕様書は「譲るな」と予言していた。
- **パステルのベタ塗り円盤** (2 回報告) → 画素毎の色域クリップが円盤を単色に
  潰していた → fork 30 白解決トーン → それでも Reinhard が周縁を平らに →
  場面参照の除数 → ポスタライズ検査 t45 と符号化後ディザ (線形空間の
  ディザはガンマの浅い上端で死ぬ、実測)。
- **マジックで塗った黒い縁** → 球面周縁則は限界で正当にゼロを横切る。
  μ の [μ0,1] 再写像 (毎フレーム二分法)。
- **星野が一度も描画されていない** → 7 段の分離二分法 (極彩色プローブ法) で
  「r=100 では点が出て 2e8 では消える」を特定 — パーセク座標は f32 頂点段で
  死ぬ。カメラ随伴方向シェルで解決。
- **エポック対の不変則** — star(epoch) は必ず Sun(同じ epoch 格子・同じ補間重み)
  と対にする。破ると共有銀河回転が幻の構造に化ける。三つの形で三回測定された。
- **最深のバグ** — census 0 成分 → 診断で「可視 11905 / 前方 0」→ 300 Myr
  エポック格子 vs 200–280 Myr 差動周期: デカルト補間が軌道を丸ごと弦で渡って
  いた。共回転系でも直らない (4/11905)。円筒位相アンラップ格納 (fork 32)。
- **実眼の空はほぼ空だった** — すべての空検証が眼を置換していて、実眼の
  フレームは一度も測定されていなかった。追跡カタログの裸眼星は +1 億年で
  11905→385、終端で 85 (視野内 3–5)。これは有限標本の偽像であり、定常性の
  定理が正しい空 (星座は溶け、星数は保たれる) を要求した → fork 33。
- **緑の背景** → 三つの別原因が重なっていた: (a) void のディザ無し生値書込が
  1–3/255 の霞を硬い縁の雲形にポスタライズ (fork 34)、(b) 暗順応 12 s が
  スライダーの手の速さより遅い (fork 28 修正 4.5 s)、(c) アプリ既定カメラ高度 0°
  が宣言構図 25° と乖離 — 「軸を見下ろすカメラは腰を描けない」とハーネス自身が
  注記していた角度で出荷していた。
- **不自然な半円** → 帯の正距円筒 uv を頂点補間していた。極で atan2 の巻き
  戻りが三角形内に塗り広げられ同心弧になる。フラグメント毎計算で解決。
  以前の増幅画像に写っていた「放射状のスジ」も同じ欠陥だった。
- **測定の自己訂正** — スライダー経路の星数として報告した 183/461 は円盤画素の
  混入 (マスク不足) だった。台帳に訂正を明記 — 測定者も測定対象である。

### 第三部 — 教訓

1. **検証された経路と、ユーザーが歩く経路は違う。** ゲートは明示 URL パラメータ
   で撮る。ユーザーは既定値で歩く。乖離は三度別の顔で現れた (高度 0°、
   カメラ張り付き、眼の置換)。報告経路の再現ツール (userpaths.mjs) を
   ハーネスに常備することが最終的な答えだった。
2. **「正直な描画」は「伝わる描画」を免除しない。** 至近距離で眼が掴まれて
   夜が来ないのは物理として正しいが、無言の黒画面は嘘と区別できない。
   作品自身が語る (「引けば夜が来る」「あなたは星雲の内側にいる」)。
3. **前提はデータに殺させる。** 本作で最も良い部分 — 青い燃え殻、勝つトラック、
   眼を掴む CIA、生死を分けないトグル — はすべて、殺された前提の墓標である。
