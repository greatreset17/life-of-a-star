# 操作手順書 — The Life of a Star

太陽の一生 (原始星 → 黒色矮星) を、公表データだけから導出された色で
たどるインタラクティブ作品の操作説明書。

---

## 1. 起動

```
cd life-of-a-star
python3 -m http.server 8000 --directory app
# ブラウザで http://localhost:8000/ を開く
```

アプリはローカルの計算済み表 (`app/data/`) だけを読み込みます。
表が欠けている場合は代用せず、欠けた名前を画面に表示して該当部分を
描きません (空白は情報です)。

### ディープリンク (URL パラメータ)

特定の瞬間・構図を URL で共有できます:

| パラメータ | 意味 | 例 |
|---|---|---|
| `?wp=` | 波形点名へジャンプ | `?wp=planetary_nebula_peak` |
| `?s=` | スライダー位置 (0–1) を直接指定 | `?s=0.52` |
| `?cam_d=` | カメラ距離 (現在の恒星半径の倍数) | `?cam_d=8` |
| `?cam_az=` / `?cam_alt=` | カメラ方位角 / 高度 (度) | `?cam_az=90&cam_alt=25` |
| `?tier=` | 描画品質 `high` / `low` | `?tier=low` |

## 3. 操作

### スライダー (画面下)

時間軸です。目盛りは**弧長 s** (0–1) — 恒星の状態変化の道のりに比例して
振られており、恒星時間には比例しません (静かな主系列は縮み、激動の
巨星期・惑星状星雲期は広がります)。現在の s 値は計器パネル先頭に表示。

### play / pause ボタン

現在位置から終端まで**全行程 120 秒**の速度で自動再生します。
- 終端に達すると自動停止。終端付近で押すと最初から再スタート。
- 再生中のスライダー操作はシークとして扱われ、再生は続きます。
- 再生中も暗順応の過渡は正直に払われます (明→暗で数秒かけて眼が慣れる)。

### 波形点ボタン (9 個)

押すと該当の瞬間へ**構図つきのカット**で切り替わります (眼は新しい場面に
順応済みで到着)。カメラは宣言された構図 (距離 4 / 方位 0° / 高度 25°、
終焉のみ 8 / 90° / 25°) に組み直されます。

| ボタン | 何が起きているか |
|---|---|
| protostar contraction | 収縮する原始星 (~4100 K の琥珀色 — 黄色く見えるのは正しい) |
| zams | 主系列到着。水素燃焼の点火 |
| present day | 現在 (4.57 Gyr)。暖かい白 (1.000, 0.861, 0.851) — 「白い太陽」も導出結果 |
| subgiant | 中心水素枯渇後、外層の膨張が始まる |
| rgb tip | 赤色巨星枝の先端。地球の運命が決まる場所 (抗力ありならここで飲み込まれる) |
| agb thermal pulses | 漸近巨星枝の熱パルス。激しい質量放出 |
| planetary nebula peak | 惑星状星雲の最盛期。**カメラは星雲の内側**にいます — 空全体が緑に光るのはそのため |
| wd crystallisation | 白色矮星の結晶化開始 (パネルに結晶化率が出ます) |
| black dwarf terminus | 終焉 — 銀河の帯の下、青い燃え殻。スタンドインの星空 (後述) |

### drag physics: on / off

地球軌道計算の**潮汐抗力**の有無を切り替えます。重要な事実: このトグルは
地球の**生死を分けません** (どちらでも地球は失われます)。分けるのは
**いつ・どこで**か —
- **on**: 赤色巨星枝の先端で引き込まれる (6.766 Gyr)
- **off**: RGB 先端を 0.226 AU の差で躱すが、その後 AGB が軌道を
  0.589 AU 越えて達する (6.892 Gyr)

### マウス / ホイール

- **ドラッグ** — カメラが恒星の周りを旋回します (慣性つき)。背景の星空が
  流れるのは視線方向が変わるためで、正しい挙動です (この距離では恒星視差は
  サブピクセル — 空は剛体的に流れます)。
- **ホイール** — カメラ距離 (現在の恒星半径の 1.15〜60 倍)。
  **暗い時代に画面が黒く見えたら、引いてください** — 至近距離では燃え殻で
  さえ眼を掴み、夜が来ません。この状況では画面上部に注記が出ます
  (「this close, even an ember holds the eye — pull back and the night arrives」)。

## 4. 計器パネルの読み方 (右下)

パネルは飾りではなく**プローブ面**です — 検証ハーネスはここに表示される
数値だけを読んで作品を判定しています。

### 基本状態

| 行 | 意味 |
|---|---|
| slider s (arc length) | スライダー位置 (弧長) |
| age | 恒星年齢 |
| phase | 進化段階名 |
| data state | `tabulated` (表内) / `extrapolated` (領域 B — データ地平線の先、宣言済み外挿) |

### L = 4πR²σT⁴_eff — シュテファン・ボルツマン則

恒星の光度は「表面積 × 温度の 4 乗」。この行の下に、その構成要素:

| 行 | 意味 |
|---|---|
| T_eff (K) | 有効温度 (表面の放射温度) |
| log L / L☉ | 光度 (太陽比、常用対数) |
| R / R☉, R (AU) | 半径 (太陽半径比 / 天文単位) |
| log g | 表面重力 (cgs、対数) |
| M / M☉ | 質量 (太陽比) — 巨星期の質量放出で減っていく |

### N = 4R² / D² — 粒状斑の枚数

対流の細胞 (粒状斑) の枚数は「恒星の表面積 ÷ 細胞の面積」。

| 行 | 意味 |
|---|---|
| granule count — derived | 物理から導出された枚数 (太陽で ~10⁶ 個規模) |
| granule count — rendered | 画面が実際に解像している枚数 — **両方を正直に表示** (画面解像度が導出値を描き切れないとき、その事実を隠さない) |
| granule diameter | 粒径。白色矮星期には km 単位まで縮む (0 km 表示はサブ km) |

### F(λ) → x̄ȳz̄ → XYZ → sRGB — 色の連鎖

いま画面の恒星の色が**どう導出されたか**の全経路: スペクトル F(λ) を
CIE 1931 等色関数 (x̄ȳz̄) で畳み込み → XYZ 三刺激値 → 線形 sRGB。

| 行 | 意味 |
|---|---|
| linear sRGB in use | 実際に使用中の線形 RGB 値 |
| gamut excursion (Oklab C) | 色域からの逸脱量 — ディスプレイが表せない彩度を Oklab 空間でどれだけ圧縮したか。0 なら無圧縮の忠実表示 |

### 星雲・地球・その他

| 行 | 意味 |
|---|---|
| shell 方程式の行 | 相互作用する恒星風モデル — 速い風が遅い超風を殻に掃き集める |
| neb_r / neb_v / neb_x | 殻の半径 (AU) / 膨張速度 (km/s) / 電離度 |
| crystal_frac | 白色矮星コアの結晶化率 |
| a_earth (AU) | 地球の軌道長半径。飲み込まれると「— (engulfed)」 |
| mdot | 恒星の質量放出率 (M☉/yr) |
| adaptation | 眼の順応状態: photopic (明所視) / mesopic (薄明視) / scotopic (暗所視) |
| sky visible | 眼に見える星の数。`(N stand-ins — identity horizon, fork 33)` は後述 |
| frame ms | 描画時間 (p95) |

### 「stand-ins」とは (fork 33)

深い時間では、いまの星座の星々は銀河軌道上へ散らばり、裸眼の空から
去ります。しかし現実の空なら別の星々が入れ替わりに近づくため、**星の
総数は保たれます** (位相混合した円盤の定常性)。カタログが追跡できない
「入れ替わりの星」を、同じ等級・色・距離・銀緯のまま方位角だけ引き直した
**スタンドイン**として描いています。何個がスタンドインかをパネルが常時
表示します。発明された数値は一つもありません。

## 5. HR 図 (右上)

ヘルツシュプルング・ラッセル図 — 恒星進化の地図。

- **横軸**: 有効温度 T_eff (K)。**右へ行くほど低温** (天文学の慣習)
- **縦軸**: 光度 L/L☉ (対数、10⁻⁸〜10⁴)
- 現在位置が点で示され、軌跡が一生の道筋を描く
- **join** 印: MIST トラックと白色矮星冷却系列の接合点
- **data horizon** 印: 公表データの終端 (~1470 K)。その先 (領域 B) の
  曲線は薄く描かれる — 宣言済み外挿の視覚表現

## 6. 二曲線グラフ (左下) — R☉(s) · a⊕(s)

- **横軸**: スライダーと同じ**弧長 s** (恒星時間ではありません — スライダー
  上の位置とグラフ上の位置が常に一致します)
- **白い曲線 R☉(s)**: 恒星半径 (AU)。巨星期に 1 AU 近くまで膨れる二つの山
- **点線 a⊕(s)**: 地球の軌道長半径。質量放出で外へ漂い、抗力設定に応じた
  場所で終わる
- 白丸: 現在位置

## 7. 体験ガイド

1. **太陽は黄色くない** — 起動時の琥珀色は 4085 K の原始星の色。present day
   ボタンで現在の太陽 (暖白) と見比べてください。
2. **星座の溶解** — present day から ±10 万年 (スライダーのわずかな動き) で
   明るい星々の配置が崩れます。100 万年で星座は消滅します。
3. **地球の最期** — rgb tip 前後で左下グラフと年齢注記に注目。drag physics
   を切り替えて「いつ・どこで」が変わるのを確認してください。
4. **星雲の内側** — planetary nebula peak では空全体が緑に光ります。
   これはバグではなく、カメラが数千 AU の殻の内側 (恒星から数恒星半径) に
   いるためです。注記が語ります: 「you are inside the nebula」。
   リング (赤道腰) はドラッグで見回すと見つかります。
5. **暗順応** — 白色矮星期以降、静止して 2 呼吸待つと眼が闇に慣れ、
   星々と天の川が浮かび上がります (τ = 4.5 秒、実際の約 20 分の宣言済み圧縮)。
6. **青い燃え殻** — 終焉の星は赤くなく**青灰色**です。純水素大気の衝突誘起
   吸収 (CIA) が赤外を塞ぎ、光が可視の窓から逃げるため — 観測される
   超低温白色矮星の現象です。
7. **終焉** — black dwarf terminus ボタン: 銀河の帯の下、星々に囲まれた
   青い燃え殻。年齢注記: 「beyond here the object being rendered exists
   nowhere, and will not for a very long time」。

## 8. 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 画面がほぼ黒い (暗い時代) | 至近距離では星が眼を掴んでいます。ホイールで引くか、2 呼吸静止して暗順応を待つ (注記が出ます) |
| 背景がうっすら緑 (星雲期) | 星雲の内側にいます — それが星雲の光です |
| 星がマウスと一緒に動く | カメラ旋回による正常な見え方 (視差はサブピクセル) |
| 「unavailable: …」表示 | 該当の Stage-0 表が欠けています。`pipeline/` の該当ビルダーを実行してください |
| 起動しない / 真っ白 | ローカルサーバ経由で開いているか確認 (file:// では module 読込が失敗します) |
